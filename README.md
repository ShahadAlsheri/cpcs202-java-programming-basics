# Java Programming 
All projects are implemented in Java and cover fundamental programming concepts.

##  Overview

### 1
1. **1.1.java** – Determines the quadrant or axis of a point based on X and Y coordinates.  
2. **1.2.java** – Sorts three numbers in ascending order.  
3. **1.3.java** – Calculates total price based on menu selection and quantity.

### 2
1. **2.1.java** – Prints sequences using loops.  
2. **2.2.java** – Finds the alphabetical position of a letter.  
3. **2.3.java** – Counts votes for Alcohol, Gasoline, Diesel until user stops input.  
4. **2.4.java** – Tracks total and percentage of different animals in a survey.

## Topics Covered
- Conditional statements (if, switch)  
- Loops (for, while, do-while)  
- Methods  
- Basic input/output  
- Arrays and simple calculations

## Language
- Java
